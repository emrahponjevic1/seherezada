# Šeherezada

Sajt restorana Šeherezada u Ljubljani — Next.js App Router, Tailwind, TypeScript.

Plan izrade je u [plan/ZAVRSNI-PLAN.html](plan/ZAVRSNI-PLAN.html); uputa za rad po koracima u [plan/UPUTA-ZA-AGENTA.md](plan/UPUTA-ZA-AGENTA.md).

```bash
npm install
npm run dev      # razvoj na http://localhost:3000
npm run build    # produkcijska gradnja
npm run start    # pokretanje izgrađene verzije
npm run lint
```
